# APEX Exchange interface prototype

Mobile-first dark crypto exchange interface branded APEX. Includes public Binance ticker and kline API calls, market filters/search, selectable BTC/USDT-style pairs, chart intervals, and a non-executing order form. Account, balances, orders, deposits, and withdrawals are not connected; the UI must not be treated as a real exchange.

Serve this directory over HTTP for testing. The Android wrapper uses the same assets under `apex-android/app/src/main/assets/apex`.
